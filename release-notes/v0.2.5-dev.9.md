# 0.2.5-dev.9 — 讨论留在 Workflow 内

仅 dev 开发版本，未发布 npm。更新插件并刷新或重启客户端后生效。

- 流程规划、模板适配/提炼、任务讨论、成员配置、人工验收继续使用可恢复的后台会话，但交互入口只保留在 Workflow 窗口；移除跳转完整 DSH 会话的按钮。
- 新讨论采用 Harness 已有的 `origin: subagent` 展示分类，普通 Session 列表和搜索会排除这些辅助会话。不设置执行父会话，不继承队长聊天记录，不授予执行或审批权限。
- 旧讨论的持久化头不可变。客户端按 TeamFlow 专用讨论 ID，在只读列表快照中补上同样的展示分类；保留 ID、历史、投影和会话引用，既不删除也不归档。适配层支持热更新引用计数、快照稳定性与卸载还原，不修改宿主依赖文件。
- 不再主动把讨论会话加入队长工作区；主对话、执行成员及普通用户会话保持原有展示规则。

固定 Harness 0.2.1-rc.2 的原生打包测试验证创建、连续讨论、重开复用、冷恢复、提案审批和执行路径；新增展示测试使用该版本发布产物的实际可见性谓词验证普通列表/归档筛选，检查搜索复用同一规则。相关 86 项测试通过。旧讨论适配依赖宿主公开列表快照和辅助会话分类；未来宿主若改变列表契约，需要重新验证。尚未在用户其他服务器逐一部署验证。
