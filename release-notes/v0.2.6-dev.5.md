# 0.2.6-dev.5 · Workflow 一级入口

- 左侧 Workflow 与插件、自动化并列，无需先打开工程即可浏览模板、填写需求。
- 应用模板时选择已有工作区，或通过「添加工作区」选择目录；Windows 系统选择器支持新建文件夹，无原生选择器时可输入目录路径。取消和返回修改保留输入。
- 在目标工作区创建独立对话，直接进入画布与任务适配讨论；自动空白会话不作为工作区选择依据。失败重试复用同一创建过程，避免重复应用模板。
- 使用宿主公开的侧栏与工作区接口；旧宿主缺少可选能力时保留原有对话入口。全局模板库仍受宿主认证保护。

验证：构建与针对性回归；在隔离 Harness 0.2.1-rc.2 中加载打包产物，验证一级入口、需求保留、系统文件夹选择/新建/取消、已有工作区选择、创建后画布和任务讨论。测试使用本地模拟模型验证接线，不代表真实模型任务生成质量。
