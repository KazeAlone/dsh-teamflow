# 0.2.5-dev.13 — 套用模板后保留主对话入口

仅 dev 开发版本，未发布 npm。更新服务并刷新客户端后生效。

模板库点击“使用模板并讨论本次任务”后，将模板名称、本次需求和已创建的团队 ID 送入绑定的主对话，启动正常的确认轮次。此前主会话始终没有 turn/start，被宿主当作空白会话从 Session 列表排除；现在可以在列表中继续打开主对话，正常持久化并在重启后保留。

任务细化仍在 Workflow 内独立讨论；其内部会话仍隐藏。主对话仅请求简短确认并等待 Workflow 中的方案确认，不重复创建团队或自动执行。相比此前会多一次主对话确认的模型请求。仅浏览模板、应用失败和重复应用请求不会发送这条消息。

覆盖模板路由成功/失败/重复调用、主对话普通会话身份、真实轮次、需求历史持久化、冷恢复，以及原有内部讨论隐藏规则。修复针对更新后新套用的模板，不批量改写已有会话历史。

验证：86 项相关测试通过；Harness 0.2.1-rc.2 下打包集成测试及冷恢复通过（模型回复脚本化）；构建、README 版本和构建产物一致性检查通过。
