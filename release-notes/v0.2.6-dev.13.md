# 0.2.6-dev.13 — Continue after returned review

Development build on `dev`; stable `main` is unchanged.

- Fix the dead end after returning a human review: the review panel now provides actions to review current results again or rerun a selected upstream task with explicit repair instructions. Returned reviews also appear in Needs attention.
- Reopening starts a new round with fresh evidence and retains the previous decision and evidence snapshot. It does not approve, dispatch tasks, or call a model. Stale state and ineligible checkpoints are rejected.
- Repair uses the existing task rerun mechanism, retains prior output, and exposes the existing continuation-path control in the review panel. Other affected branches remain paused and human checkpoints still require approval.
- Archived and historical decisions remain read-only. Regression coverage includes route transitions, preservation of history, branch isolation, localized controls, and browser interaction.
