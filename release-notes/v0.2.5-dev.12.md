# 0.2.5-dev.12 — 模板提炼结构化参数与真实模型复测

仅 dev 开发版本，未发布 npm。更新服务并刷新客户端后生效。

- 保留 dev.11 的单份任务描述：普通创建一次提交完整任务；应用模板时讨论细化；通用要求只在保存模板时提炼。
- 修复保存模板的工具参数：`agent_teams_template_propose.definition` 直接接收结构化对象，成员、节点和通用要求均有明确字段类型，不再要求模型生成内嵌 JSON 字符串。旧字符串接口不兼容。
- 画布位置由服务端从源流程保留，不再要求模型复制坐标。源成员、任务和结构保持不变；保存仍需用户确认。
- 真实模型测试驱动增加 `--save-template`，在创建或模板应用后验证提炼、保存与源任务不变，并记录模型和工具错误。

复测发现旧提炼接口连续出现 4 次 JSON 解析错误，随后 3 次文本校验错误，最终失败。修复后重复测试及内容人工复核见 [测试记录](../docs/single-description-audit-2026-11-02.md)。格式成功与描述内容正确分别评估，不将少量样本视为所有小模型的成功率。
