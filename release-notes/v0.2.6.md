Stable Git installation: github:yogurtss/dsh-teamflow#main. Development remains on dev; the classic tag is unchanged.

- Open Workflow from the sidebar, choose a template, and select or create a workspace. Review complete task requirements before starting.
- Inspect checkpoint evidence beside the canvas, compare saved review rounds, return work with a reason, arrange repairs, and approve the next round.
- Browse Deliverables from task submissions and declared files without additional model calls. Current workspace previews are clearly distinguished from saved approval evidence.
- Start all continues unfinished, paused, and interrupted work without extra input. Run through a node releases its required upstream path and pauses later descendants. Completed work is preserved; explicit reruns require instructions.
- Show compact progress and action counts, with Setup needed for configuration-only issues. Explain blockers and provide recovery actions.
- Preserve pause fences and attempt generations across recovery. Bound workflow, node-control, launcher, and discussion requests without replaying uncertain mutations.
- Fix completed reruns incorrectly displaying an updating notice. Refine cards, navigation, proposal review, streaming discussions, and bilingual documentation.
