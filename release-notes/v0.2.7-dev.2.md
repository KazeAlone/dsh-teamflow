# 0.2.7-dev.2 — Bound and reuse loading work

Development build on dev; stable installations remain on main.

- Share identical concurrent read requests, cancel readers independently and bound stalled reads. Mutations are never combined or replayed.
- Reuse bounded discussion/catalog display caches while refreshing authoritative state. Reduce repeated discussion-history conversion and omit unchanged history payloads, including correct streaming/status invalidation.
- Coalesce Agent catalog lookups and prevent a slower earlier click from replacing the latest conversation selection.
- Bound file/member reads, stop overlapping template polls, and reduce hidden-page polling while preserving activity status synchronization.

Full local verification and isolated browser delayed-reopen checks passed. Native DSH Agent transcript hydration remains host-owned; no remote-server speedup is claimed without measurements. See [the loading audit](../docs/performance-0.2.7/loading-audit.md) for each entry and its safety boundary.
