# 0.2.6-dev.15 — Resume the full workflow after rework

Development build on `dev`; stable `main` is unchanged.

- Start all now confirms pending reruns and enables all configured unfinished nodes, fixing its disabled state when only rerun-paused nodes remain.
- Execution follows dependencies and waits at human checkpoints. After approval, enabled downstream tasks run without another start action. Start all never approves a review or retries a failed task implicitly.
- Pause all retains the existing scheduling fences and drain behavior. Unconfigured nodes, rejected reviews, and terminal results are preserved. Individual task and scoped rerun controls remain available.
- Validation covers start-after-repair, automatic dispatch after approval, pause/resume, stale requests, and existing workflow behavior.
