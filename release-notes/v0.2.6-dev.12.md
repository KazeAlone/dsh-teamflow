# 0.2.6-dev.12 — Outcome showcase

Development build on `dev`; stable `main` is unchanged.

- Workflow → Outcomes groups task submissions, reported checks, declared deliverables, and reported file changes. No LLM calls are used for collection, organization, or preview.
- Preview current Markdown, UTF-8 text/code, CSV, and PNG/JPEG/GIF/WebP files. HTML remains escaped text; external embeds and active documents are not executed. Text is capped at 256 KiB and images at 4 MiB.
- Read-only previews require team ownership and an exact task-declared path. Workspace escapes, links, private state, and excluded paths are blocked.
- Current workspace files are explicitly distinguished from historical submission text and human approval. Existing task and review workbenches remain the action destinations.
- Chinese and English labels, bounded CSV parsing, route ownership/read-only checks, safe file previews, browser navigation, and existing workflow regressions are covered by validation.
