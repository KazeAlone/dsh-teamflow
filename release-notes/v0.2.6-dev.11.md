# 0.2.6-dev.11 · 验收工作台

- 人工检查点的验收入口在现有 Workflow 内打开专用工作台，复用节点详情、待处理和主对话提醒。支持画布旁查看、放大面板、完整要求、同名提交条目、命令记录、文件摘要与读取缺口。
- 新审批保存经过原有指纹校验的证据快照，支持轮次选择与前后提交记录对比；历史记录没有快照时不重建或伪造证据。文件对比仅表示摘要或读取状态变化，不宣称展示源码 diff。
- 保留既有人工审批、依赖调度、返工提案和重跑边界。通过前需确认，退回需填写原因；意见按团队、检查点和轮次隔离。仅查看材料不触发模型，AI 讨论按需打开并沿用已有独立会话。
- 中英文界面、窄屏布局、归档只读和未就绪状态均纳入检查。执行 Agent 报告与人工验收结果明确区分；自由文本要求保持完整，不自动拆分或推断覆盖关系。

开发版安装：`github:yogurtss/dsh-teamflow#dev`。验证范围与复现步骤见 [验收工作台验证记录](../docs/review-workbench-2026-11-06/README.md)。
