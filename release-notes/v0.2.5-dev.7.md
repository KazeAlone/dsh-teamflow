# 0.2.5-dev.7 — 创建提案参数契约修复

仅 dev 开发版本；main / classic 不变，未发布到 npm。

- 修复工作流提案 Schema 要求 operations 数组，但配置顾问提示词仍要求 JSON 字符串的冲突。
- 用包含成员与分层任务的完整 JSON 调用示例替换伪代码；明确 layers/general/specific 是对象，requirements/deliverables/acceptance 是字符串。
- 补充操作字段的适用条件、无依赖任务的空数组写法，以及无关可选字段应省略的说明。所有创建入口共用的分层 Schema 明确禁止字符串化对象与数组形式的交付物、验收项。
- 分层业务校验指出具体字段路径和收到的类型，工作流批次包含 operations 索引；继续拒绝错误类型，不猜测任务内容、不修改审批或模板约束。
- 新增回归：实际注入的提示词示例经过 Harness 工具 Schema、业务校验和人工应用路径；错误参数不得保存提案或修改团队。同步模型可见工具契约快照。

本批次保留现有双层创建和整批模板适配流程。模板适配只提交可变内容、普通创建轻量化和局部草稿重试尚未实现；不能据此宣称小模型成功率或耗时已经改善。
